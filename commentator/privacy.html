Privacy policy

Last updated 12 September 2026.

commentator is a personal, single-user application operated by its owner for the owner’s own YouTube channel. It is not distributed, sold or made available to the public. This policy describes how it handles data.

Data accessed

With the owner’s explicit Google authorisation, the application uses the YouTube Data API to read comment threads on the owner’s own videos (comment text, the commenter’s public display name, profile image and channel identifier, like counts and timestamps), the owner’s list of uploads, and — where the owner enables it — the list of the owner’s public subscribers and channel members. It posts replies to comments only when the owner explicitly sends one.

Storage

The data is stored in a database on a server owned and controlled by the owner, reachable only over the owner’s private network. It is not stored on any third-party service and is not accessible to anyone but the owner.

Use

The data is used solely to display the owner’s comments in an inbox, to let the owner organise them, and to suggest replies based on the owner’s own previous replies. It is not used for advertising, profiling, resale or training of any external system.

Sharing

No data is shared with, sold to or transferred to any third party. The only outbound traffic is to Google’s YouTube Data API for the purposes described above.

Google API Services User Data Policy

The application’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is retained for as long as the owner keeps the application. The owner can delete all stored data at any time by deleting the application’s database, and can revoke the application’s access at myaccount.google.com/permissions, which immediately invalidates its credentials.

Contact

Questions about this policy can be sent through the contact details on this site.
